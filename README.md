# WeZePlay Portfolio

A no-build-step portfolio website for Noah, made with plain HTML, CSS, and JavaScript.

## Run it

Open `index.html` in a browser. No installation or build command is needed.

## Update projects

Edit `data/projects.js`. Each project is shown on `projects.html`; projects with `featured: true` also appear on the home page.

## Deploy

Upload the contents of this folder to a GitHub repository and enable GitHub Pages from its default branch.
